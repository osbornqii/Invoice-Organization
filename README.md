# 票据管理系统

基于 UniApp + Vue 3 构建的跨平台票据管理解决方案，支持网页端（H5）和微信小程序双端运行，专注于 PDF 发票文件的批量上传、智能识别与整理归档。

## 核心功能

**批量文件处理**：支持多文件同时上传，提供拖拽和点击两种上传方式，实时显示上传进度和处理状态，文件大小限制 10MB 以内。

**智能票据识别**：自动解析 PDF 文件内容，通过 OCR 技术提取发票关键信息，包括发票类型、发票号码、开票日期、金额（含税/不含税）、税额等字段。

**分类管理**：自动将识别结果按发票类型分类展示，包括增值税专用发票、增值税普通发票、电子发票等类别，支持标签页快速切换和统计汇总。

**结果编辑**：识别结果支持手动编辑校正，可修改发票号码、日期、金额等字段，确保数据准确性。

**数据导出**：支持将识别结果导出为 Excel 格式，便于后续财务管理和数据统计。

**友好提示**：智能检测非发票文件并给出明确提示，详细的错误信息帮助用户快速定位和解决问题。

## 技术栈

**前端框架**：Vue 3.5.12 + UniApp 3.0，兼顾开发效率与性能表现。

**构建工具**：Vite 5.2.8，提供极速的开发体验和优化的生产构建。

**PDF 处理**：pdfjs-dist，前端直接解析 PDF 文件转换为图片，减少服务器压力。

**样式方案**：SCSS + Flexbox 布局，实现响应式设计和跨平台一致性。

**数据处理**：xlsx，用于发票数据的 Excel 格式导出。

## 环境要求

- Node.js 16.x 或更高版本
- npm 8.x 或更高版本
- 微信开发者工具（开发微信小程序时需要）

## 安装部署

### 安装依赖

```bash
npm install
```

### 开发模式

**启动 H5 开发服务器**：

```bash
npm run dev:h5
```

访问地址：`http://localhost:8080`

**启动微信小程序开发模式**：

```bash
npm run dev:mp-weixin
```

使用微信开发者工具导入 `dist/dev/mp-weixin` 目录。

### 生产构建

**构建 H5 版本**：

```bash
npm run build:h5
```

构建产物位于 `dist/build/h5` 目录，可直接部署到静态服务器。

**构建微信小程序版本**：

```bash
npm run build:mp-weixin
```

构建产物位于 `dist/build/mp-weixin` 目录，使用微信开发者工具导入并发布。

## 微信小程序配置

### 应用标识

在 `manifest.json` 文件中配置微信小程序的 appid：

```json
{
  "mp-weixin": {
    "appid": "your-wechat-appid"
  }
}
```

### 服务器域名

如果使用云函数或后端服务，需要在微信公众平台后台配置合法域名：

- request 合法域名
- uploadFile 合法域名
- downloadFile 合法域名

### 权限配置

微信小程序已配置以下权限：

- 用户位置信息（用于发票信息展示）

## 使用说明

### 基本流程

1. 打开应用首页，点击上传区域或拖拽 PDF 文件到上传区域。
2. 选择需要处理的发票 PDF 文件，支持多选。
3. 点击「开始解析」按钮，系统将自动识别发票信息。
4. 等待处理完成后，自动跳转到结果页面查看识别结果。
5. 在结果页面可以编辑、删除识别结果，或导出为 Excel 文件。

### 注意事项

- 上传的 PDF 文件必须是发票相关文档，非发票文件会被系统提示。
- 单个文件大小不能超过 10MB。
- 处理过程中请保持网络连接稳定。
- 识别结果可手动编辑校正，以提高数据准确性。

## 开发相关

### 跨平台开发

本项目采用 UniApp 框架实现跨平台兼容，关键的平台差异化处理通过条件编译实现：

```javascript
// H5 平台
#ifdef H5
// H5 特定代码
#endif

// 微信小程序平台
#ifdef MP-WEIXIN
// 小程序特定代码
#endif
```

### PDF 处理

PDF 解析在 H5 端使用 pdfjs-dist 直接在浏览器中处理，在微信小程序端通过云函数调用后端服务处理。

### OCR 识别

发票信息识别依赖于后端 OCR 服务，需要部署相应的云函数或对接第三方 OCR 接口。
